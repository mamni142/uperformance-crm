# Uperformance – hemsida och CRM-demo för visning

Den nya hemsidan med inloggning och en klickbar demo av CRM:et (påhittad exempeldata – allt man gör sparas bara i den egna webbläsaren).
Byggd ur projektets ögonblicksbild HEAD. Sprid inte länken vidare.

- Hemsidan: roten (`index.html`) – "Logga in" i menyn leder till inloggningen
- Inloggning: `crm/logga-in.html` (välj ett konto – inget lösenord)
- Direkt in som säljare: `crm/?visa=salj` (eller `?visa=chef`, `?visa=test`, `?visa=admin`)
