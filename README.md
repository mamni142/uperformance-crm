# Uperformance CRM – demo för visning

Klickbar demo av Uperformance CRM med påhittad exempeldata. Allt man gör sparas bara i den egna webbläsaren.
Byggd ur projektets ögonblicksbild 702160d. Sprid inte länken vidare.

- Inloggning: `crm/logga-in.html` (välj ett konto – inget lösenord)
- Direkt in som säljare: `crm/?visa=salj` (eller `?visa=chef`, `?visa=test`, `?visa=admin`)
